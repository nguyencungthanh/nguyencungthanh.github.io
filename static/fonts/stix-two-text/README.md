# STIX Two Text

- Project: https://github.com/stipub/stixfonts
- License: SIL Open Font License 1.1 (see OFL.txt)
- Webfont source: Google Fonts, version 18
- Included subsets: Latin, extended Latin, Greek, and Vietnamese
- Variable weights: 400–700, roman and italic

These unmodified WOFF2 files are served locally for Mathematics Blog and Algorithm Project articles.
MathJax continues to render formulas independently as TeX SVG paths.
